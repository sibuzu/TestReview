## 第27題｜@錯題 融合模式 v2.1

<badge color="success">原選 A → 正解 C</badge>

**核心觀念：未滿18歲不代表完全不會被判刑。少年在特定情況下，仍可能受到刑事處分。**

### 一、原題證據核對

題目中的法官說：

> 雖然你尚未成年，但是犯罪行為……因此處以有期徒刑。

題目問：下列何者與這名少年的情形相同？

| 選項 | 年齡與行為 | 判斷 |
|---|---|---|
| (A) | 17歲阿明偷錢 | 不選 |
| (B) | 18歲香香辱罵男友 | 不選 |
| **(C)** | **14歲胖虎持刀強迫同學上繳財物** | **正確** |
| (D) | 13歲麗婷因爭風吃醋毆打情敵 | 不選 |

這題的決勝關鍵是：**年齡是否達到刑事責任門檻，以及犯罪行為是否可能受到刑事處罰。**

### 二、四選項逐項辨析

**(A) 17歲阿明偷錢 — 不選**

17歲已具刑事責任能力，但一般竊盜案件通常優先依少年保護事件程序處理，不代表必然判刑。若情節重大，仍可能進入刑事程序。

**(B) 18歲香香辱罵男友 — 不選**

18歲已不屬於《少年事件處理法》所稱的少年，與題幹「尚未成年」的少年刑事案件情境不同。

**(C) 14歲胖虎持刀強迫同學上繳財物 — 正確**

14歲已達刑事責任年齡，持刀強迫交出財物可能構成強盜等重大犯罪，有可能進入少年刑事程序並受到有期徒刑處分。<Cite refs={["turn450123search9","turn450123search14"]}/>

**(D) 13歲麗婷毆打情敵 — 不選**

依《刑法》第18條，未滿14歲不負刑事責任，但仍可能依少年保護制度處理。<Cite refs={["turn450123search3","turn450123search5"]}/>

### 四、二選一決勝：A 與 C

| 判斷條件 | A 偷錢 | C 持刀強迫交財物 |
|---|---|---|
| 達刑事責任年齡 | 是 | 是 |
| 犯罪情節 | 一般竊盜 | 可能構成重大強盜犯罪 |
| 與題目判處有期徒刑的典型情境 | 較不符合 | **較符合 ✓** |

考場快速判斷：

**「滿14歲可能負刑責；少年犯重罪，也可能被判刑。」**

但不能記成「竊盜絕不判刑」或「持刀一定判刑」。本題 C 是四個選項中最符合題幹者，實際罪名與刑度仍須依個案事實認定。

- **P1：** 已比較誤選 A 與正解 C，補充少年竊盜也可能進入刑事程序的例外。
- **P2：** 已提供年齡與刑事責任比較圖。
- **教材查核：** 已核對司法院及法務部法規資料，未使用國中教材唯讀搜尋。
- **實際錯因：** 資料不足，不能直接判定是忽略犯罪嚴重性。

**本題最值得改善的一個判斷習慣：先確認年齡，再判斷犯罪情節及可能適用的處理程序，不要只看是否未成年。**
