### 一、原題與四選項核對

**題目：** 小寶穿著溜冰鞋推牆壁，若小寶對牆壁施加向左 50 kgw 的力，下列敘述何者**錯誤**？

| 選項 | 敘述重點 | 判斷 |
|---|---|---|
| A | 牆反推小寶 50 kgw | 正確 |
| B | 接觸牆壁期間，小寶有向右的加速度 | 正確 |
| C | 小寶體重愈輕，產生的加速度愈大 | 正確（相同合力下） |
| **D** | **手離開牆壁後，不計地板摩擦力，小寶速度愈來愈大** | **錯誤 ✓** |

依題意，離開牆壁後，沒有牆的推力，也忽略地板摩擦力，因此水平方向合力為零。

\[
\boxed{F_{\text{合}}=0\ \Rightarrow\ a=0}
\]

加速度為零，不代表速度為零，而是**速度保持不變**。

### 三、B 與 D：最後二選一決勝

**原選 B：與牆接觸期間，小寶有向右的加速度。**

正確。小寶向左推牆，牆便給小寶向右的反作用力。若水平其他力可忽略，小寶受到向右的合力，因而向右加速。

**正解 D：手離開牆壁後，速度愈來愈大。**

錯誤。手離開牆壁後，不再受到牆壁的推力。如果沒有水平摩擦力，速度不會繼續增加，而是保持離開瞬間的速度。

| 決勝條件 | B（原選） | D（正解） |
|---|---|---|
| 是否接觸牆壁 | 是 | 否 |
| 牆是否施加推力 | 是 | 否 |
| 水平加速度 | 向右 | 零 |
| 運動情形 | 向右加速 | 向右等速度 |

### 四、會考快速判斷法

看到「推牆後滑行」這種題目，要先分成兩個階段：

<box background="surface-secondary" radius="lg" padding={3} gap={2}>
  <row align="center" justify="between">
    <text weight="medium">正在推牆</text>
    <text weight="medium" color="success">有反作用力 → 加速</text>
  </row>
  <divider color="subtle"/>
  <row align="center" justify="between">
    <text weight="medium">離開牆壁</text>
    <text weight="medium">無水平合力 → 等速度</text>
  </row>
</box>

**別把「持續運動」誤認成「持續加速」。**

### 五、本題誤選診斷

可能的判斷陷阱是：認為推牆時作用力、反作用力會相互抵銷，因此懷疑 B 的加速度敘述。

但 B 的作用力與反作用力是作用在不同物體上，不能互相抵銷。

目前僅有 B → D 的紀錄，尚無孩子原始作答思路，所以這只是可能錯因。

這題也延伸前幾題的核心觀念：**第三運動定律判斷力的配對，第一、第二運動定律判斷物體的運動狀態。**

> **一句話記住：推牆時會加速；離開牆後若無水平合力，就等速度運動。**
