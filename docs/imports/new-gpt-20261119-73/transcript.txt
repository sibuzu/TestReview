### 一、原題與關鍵判斷

**題目：** 下列哪一組物質反應後，會產生二氧化碳氣體？

| 選項 | 反應物 | 判斷 |
|---|---|---|
| A | 鎂和稀硫酸 | 產生氫氣 |
| **B** | **碳酸氫鈉和稀硫酸** | **產生二氧化碳 ✓** |
| C | 雙氧水和二氧化錳 | 產生氧氣 |
| D | 醋酸和氫氧化鈉 | 酸鹼中和，不產生 CO₂ |

**決勝關鍵：要產生 CO₂，優先檢查反應物有沒有碳酸鹽或碳酸氫鹽。**

### 三、為什麼 D 錯、B 對？

**你選 D：醋酸＋氫氧化鈉**

這是典型酸鹼中和反應：

\[
\mathrm{CH_3COOH+NaOH}
\]
\[
\mathrm{\rightarrow CH_3COONa+H_2O}
\]

產物是醋酸鈉和水，沒有二氧化碳。

**正解 B：碳酸氫鈉＋稀硫酸**

碳酸氫鈉遇酸，會產生二氧化碳：

\[
\mathrm{2NaHCO_3+H_2SO_4}
\]
\[
\mathrm{\rightarrow Na_2SO_4+2CO_2+2H_2O}
\]

產生的 CO₂ 會以氣泡形式逸出。

### 四、會考最後二選一決勝

| 比較 | B（正解） | D（原選） |
|---|---|---|
| 有酸參與 | ✓ | ✓ |
| 含碳酸氫根 | ✓ | ✗ |
| 產生 CO₂ | ✓ | ✗ |
| 核心反應 | 酸＋碳酸氫鹽 | 酸＋鹼 |

**考場 5 秒判斷法：**

看到「產生二氧化碳」，立刻找：

- 碳酸鹽：例如 CaCO₃
- 碳酸氫鹽：例如 NaHCO₃

它們遇到酸，通常會產生 CO₂。

但要注意：**不是所有含碳的物質遇酸都會產生 CO₂。** 醋酸本身雖然含碳，與氫氧化鈉中和也不會產生 CO₂。

### 五、這題的誤選診斷

<text weight="medium">可能的判斷陷阱：把「酸鹼中和」和「酸與碳酸氫鹽反應」混淆。</text>

目前只能確認原選 D、正解 B；沒有原始作答思路，不能斷定孩子實際為何選 D。

**一句話記住：**

> 酸遇碳酸（氫）鹽，常產生 CO₂；酸遇一般鹼，主要是中和反應。

### 一、原題與關鍵判斷

題目：下列關於此反應的敘述，何者**錯誤**？

哈伯法製氨：

\[
\mathrm{N_2+3H_2\rightleftharpoons 2NH_3}
\]

反應條件：200 atm、500°C，題圖標示 Fe₂O₃。

| 選項 | 敘述 | 判斷 |
|---|---|---|
| A | 為可逆反應 | 正確，雙向箭頭 |
| B | 大量加入 H₂，可增加 NH₃ 產量 | 正確，平衡向右移動 |
| C | 改變壓力或溫度，會影響平衡狀態 | 正確 |
| **D** | **達平衡時，N₂ 與 NH₃ 的莫耳數比為 1：2** | **錯誤 ✓** |

### 三、C 與 D：最後二選一決勝

**你原選 C：改變壓力或溫度，會影響平衡狀態。**

這是正確敘述。

- 增加壓力：平衡傾向氣體莫耳數較少的一側，也就是 NH₃ 生成方向。
- 改變溫度：會改變平衡組成；製氨正反應為放熱反應，升溫通常不利於 NH₃ 的平衡產率。

**正解 D：達平衡時，N₂ 與 NH₃ 的莫耳數比為 1：2。**

錯在把**反應係數比**誤當成**平衡時實際存在的莫耳數比**。

\[
\underbrace{1:2}_{\text{N₂ 消耗量：NH₃ 生成量}}
\neq
\underbrace{\text{平衡時 N₂：NH₃}}_{\text{不能直接由係數判定}}
\]

平衡時正、逆反應速率相等，三種氣體仍然共存，各自含量由反應條件與初始組成決定。

### 四、會考快速判斷法

看到「化學平衡＋反應係數」，先問自己：

**題目是在問「反應了多少」，還是「平衡時剩多少」？**

- 問消耗量、生成量比例 → 可以使用反應係數。
- 問平衡時各物質的實際莫耳數比例 → 不能只看係數。

### 五、本題誤選診斷

可能是對「改變溫度、壓力會使平衡移動」的概念尚未完全掌握，或未注意到 D 把係數比當成平衡組成比。

但目前沒有原始作答過程，**不能直接斷定真正錯因**。

**一句話記住：**

> 化學係數告訴我們反應的數量比例，不保證平衡時各物質的剩餘比例。

<text color="secondary" size="sm">主題：酯化反應｜乙酸乙酯的製備</text>

<row align="center" gap={2}>
  <badge color="success">正確答案 A</badge>

### 一、原題與關鍵判斷

**題目：** 利用酯化反應製造乙酸乙酯時，最不需使用下列何種試劑？

| 選項 | 試劑 | 用途與判斷 |
|---|---|---|
| **A** | **NaCl（氯化鈉）** | **不是酯化反應必要試劑 ✓** |
| B | CH₃COOH（乙酸） | 反應物，需要 |
| C | C₂H₅OH（乙醇） | 反應物，需要 |
| D | H₂SO₄（硫酸） | 常用濃硫酸作催化劑，需要 |

題目問「最不需」，因此選 **A**。

### 二、精準圖解：三種試劑的角色

<box border radius="lg" padding={3} gap={2}>
  <box background="surface-secondary" padding={3} radius="md" align="center" gap={1}>
    <text weight="medium">乙酸 ＋ 乙醇</text>
    <text color="secondary" size="xs">CH₃COOH ＋ C₂H₅OH</text>

    <icon name="arrow-down" color="secondary" size="lg"/>
    <box border radius="md" padding={2} gap={1} align="center">
      <text color="default" weight="medium" size="sm">濃硫酸 H₂SO₄</text>
      <text color="secondary" size="xs">催化、幫助脫水</text>
    </box>
  </row>
  <box background="rgba(22,163,74,0.07)" border={{size:1,color:"rgba(22,163,74,0.25)"}} padding={3} radius="md" align="center" gap={1}>
    <text weight="medium">乙酸乙酯 ＋ 水</text>

  <row justify="center" align="center" gap={2}>

  </row>

化學反應式：

\[
\mathrm{CH_3COOH+C_2H_5OH}
\]

\[
\underset{\text{濃硫酸、加熱}}{\rightleftharpoons}
\]

\[
\mathrm{CH_3COOC_2H_5+H_2O}
\]

### 三、D 與 A：最後二選一決勝

**原選 D：硫酸（H₂SO₄）**

容易誤選的原因是：硫酸沒有寫在反應式的主要反應物中，因此可能認為不需要。

但事實上：

- 濃硫酸能催化酯化反應，加快反應速率。
- 濃硫酸也具有脫水作用，有利於酯的生成。
- 催化劑不會在反應中被淨消耗，**不代表不需要使用**。

**正解 A：氯化鈉（NaCl）**

氯化鈉不是製造乙酸乙酯的必要反應試劑。雖然某些實驗後處理可能使用食鹽水協助分離，但不是本題酯化反應所需的主要試劑。

| 決勝問題 | A 氯化鈉 | D 硫酸 |
|---|---|---|
| 是主要反應物？ | 否 | 否 |
| 具有催化作用？ | 否 | 是 |
| 製備酯時通常需要？ | 否 | 是 |
| 本題應選？ | ✓ | ✗ |

### 四、會考快速判斷法

看到「製造酯類」，立即想起：

**羧酸＋醇，在濃硫酸催化下，生成酯＋水。**

考場只需辨認三個角色：羧酸、醇、濃硫酸。其他試劑再依題目判斷是否必要。

### 五、本題誤選診斷

本題可能的判斷陷阱是：**把「沒有出現在反應物一側」誤認為「製備時不需要」。**

不過目前只有 D → A 的作答紀錄，沒有原始判斷過程，因此這仍是待確認的可能錯因。

**一句話記住：**

> 酯化需要羧酸和醇，常使用濃硫酸催化；催化劑不被淨消耗，但仍然有重要作用。

  <text color="secondary" size="xs">圖中以水合氫離子的簡化寫法 H⁺ 表示；Na⁺ 和 Cl⁻ 在此反應中屬旁觀離子。</text>
</box>

所以 B 的錯誤非常明確：

- B 說的是「酸的陰離子＋鹼的陽離子」。
- 正確應是「酸提供的 H⁺＋鹼提供的 OH⁻」。

### 三、D 與 B：最後二選一決勝

**原選 D：中和後的水溶液導電性可能很差。**

這個敘述是正確的，關鍵在於題目使用「**可能**」，並沒有說所有酸鹼中和後都不導電。

水溶液導電主要依靠能移動的離子。中和過程中 H⁺ 和 OH⁻ 結合成水，若剩餘可移動離子很少，導電性就可能很差。

例如稀氫氧化鋇溶液與稀硫酸恰好完全反應：

\[
\mathrm{Ba(OH)_2+H_2SO_4}
\]
\[
\mathrm{\rightarrow BaSO_4\downarrow+2H_2O}
\]

生成難溶的硫酸鋇沉澱，使溶液中離子濃度大幅降低，導電性可能變得很差。

但如果是鹽酸與氫氧化鈉中和，產生的 NaCl 仍溶於水，因此溶液通常還能導電。

**正解 B：把中和的主要反應離子完全搞反了。**

| 比較關鍵 | B（正解） | D（原選） |
|---|---|---|
| 敘述是否正確 | 錯誤 | 正確 |
| 決定性線索 | 酸陰離子、鹼陽離子 | 「可能」很差 |
| 考場檢查 | 中和主角是 H⁺、OH⁻ | 依剩餘離子判斷 |

### 四、會考快速判斷法

遇到酸鹼中和題，先記住：

\[
\boxed{\mathrm{H^++OH^-\rightarrow H_2O}}
\]

再檢查題目是否把離子正負寫反。

導電性則看「**中和後還有多少可移動的離子**」，不能認為生成鹽就一定導電，也不能認為生成水就完全不導電。

### 五、本題誤選診斷

<text weight="medium">可能的判斷陷阱：</text> 把「中和後導電性可能變差」誤認為錯誤敘述，或尚未牢固掌握中和反應的主要離子。

目前只有 D → B 的紀錄，無法確定實際作答原因。

**一句話記住：**

> 酸的 H⁺ 遇上鹼的 OH⁻ 形成水；中和後能否導電，還要看溶液中剩下哪些離子。

<row align="center" gap={2}>
  <badge color="success">正確答案 B</badge>
  <text color="secondary" weight="medium">原選 A → 正解 B</text>

### 一、原題與關鍵條件

題目：質量 \(m_1\) 的甲物體受合力 \(F\) 作用下，加速度為 \(a_1\)；質量 \(m_2\) 的乙物體受合力 \(F\) 作用下，加速度為 \(a_2\)。若將甲、乙兩物體綁在一起，並受合力 \(3F\) 的作用，則其加速度為何？

| 選項 | 算式 |
|---|---|
| A（原選） | \(3a_1a_2\) |
| **B（正解）** | \(\displaystyle\frac{3a_1a_2}{a_1+a_2}\) |
| C | \(\displaystyle\frac{a_1+a_2}{a_1a_2}\) |
| D | \(a_1a_2\) |

### 三、逐步計算

**第一步：利用 \(F=ma\) 求出兩個質量。**

甲：

\[
F=m_1a_1\quad\Rightarrow\quad m_1=\frac{F}{a_1}
\]

乙：

\[
F=m_2a_2\quad\Rightarrow\quad m_2=\frac{F}{a_2}
\]

**第二步：兩物體綁在一起，質量相加。**

\[
m_1+m_2=\frac{F}{a_1}+\frac{F}{a_2}
\]

通分：

\[
m_1+m_2=\frac{F(a_1+a_2)}{a_1a_2}
\]

**第三步：合力變成 \(3F\)，計算共同加速度。**

\[
a=\frac{3F}{m_1+m_2}
\]

代入總質量：

\[
a=\frac{3F}{\dfrac{F(a_1+a_2)}{a_1a_2}}
\]

約去 \(F\)，得到：

\[
\boxed{a=\frac{3a_1a_2}{a_1+a_2}}
\]

所以答案是 **B**。

### 四、A 與 B：最後二選一決勝

| 比較 | A（原選） | B（正解） |
|---|---|---|
| 算式 | \(3a_1a_2\) | \(\dfrac{3a_1a_2}{a_1+a_2}\) |
| 有考慮總質量？ | 沒有完整反映 | 有 |
| 單位是否為加速度？ | 不符合 | 符合 |

還可以用**單位檢查法**，不用重新計算就能排除 A。

- A：加速度 × 加速度，單位是 \(\mathrm{m^2/s^4}\)，不是加速度。
- B：兩個加速度相乘，再除以加速度，單位是 \(\mathrm{m/s^2}\)，正確。

因此考場即使通分不熟，也能快速辨認 A 有問題。

### 五、四選項逐項辨析

- **A：錯誤。** 只有 \(3a_1a_2\)，少了分母，且單位不符。
- **B：正確。** 同時考慮兩物體總質量及三倍合力。
- **C：錯誤。** 是將正確式子的分子、分母顛倒後，又缺少係數 3。
- **D：錯誤。** 未考慮新的合力 \(3F\)，單位也不符。

### 六、本題誤選診斷

目前只能確認原選 A，不能直接認定當時漏掉分母的原因。

可能的判斷陷阱是：看到合力變成三倍，就直接將兩個加速度相乘再乘三，沒有先回到牛頓第二運動定律。

**考場最值得記住的一句話：**

> 物體綁在一起，先加質量，再用總合力除以總質量；不可以直接把加速度相乘。

## @錯題｜融合模式 v2.1｜理化第18題

<text color="secondary" size="sm">主題：牛頓第二運動定律｜質量與加速度的反比關係</text>

### 一、原題與關鍵判斷

**題目：** 若實驗中施加固定的外力於不同質量的物體上，則物體獲得的加速度（a）與質量（m）的關係圖，最可能為下列何者？

關鍵是題目中的 **「固定的外力」**。

根據牛頓第二運動定律：

\[
F=ma
\]

因為外力 \(F\) 固定，所以：

\[
\boxed{a=\frac{F}{m}}
\]

因此加速度與質量**成反比**。

### 二、第 (1) 小題：哪些力互為作用力與反作用力？

<text color="secondary" size="sm">原答：F₁、F₄ 與 F₃、F₂ → 正解：F₃、F₄</text>

正確配對：

\[
\boxed{F_3\leftrightarrow F_4}
\]

因為：

- F₃ 是甲推乙。
- F₄ 是乙推甲。

它們是兩個物體互相施力，大小相等、方向相反。

**為什麼 F₁ 與 F₄ 不是一對？**

F₁ 是外界推甲，F₄ 是乙推甲。兩個力都作用在甲身上，因此不能互為作用力與反作用力。

同理，F₂ 與 F₃ 都作用在乙身上，也不是一對。

### 四、其他兩個選項為什麼錯？

**B：高速氣流減少空氣阻力。**

減少阻力不等於產生推進力，而且太空中沒有足夠的外界空氣供此機制運作。

**C：空氣浮力使火箭向上。**

浮力不是太空中火箭推進的主要原因；火箭即使在近真空環境中，也能改變運動狀態。

**先找出互相施力的兩個物體，再把施力者與受力者交換。**
